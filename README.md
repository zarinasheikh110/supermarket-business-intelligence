# Supermarket Business Intelligence Dashboard

## About the Project
This is a self-initiated data analytics project developed using Microsoft Power BI to analyse supermarket operations and transform business data into actionable insights.

## Project Objectives
- Analyse sales and transaction performance.
- Compare store performance and profitability.
- Identify top-performing products and categories.
- Explore customer segments and sales channels.
- Evaluate promotion effectiveness.
- Monitor inventory risks and waste.

## Dashboard Modules
1. Executive Overview
2. Store Performance
3. Category & Product Performance
4. Customer & Channel Insights
5. Promotion Effectiveness
6. Inventory Risk & Waste

## Tools and Skills
- Microsoft Power BI
- DAX
- Data Modelling
- KPI Development
- Data Visualisation
- Business Intelligence
